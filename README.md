## Deploying
The contents of the `jekyll` directory gets deployed from the github repository at [https://github.com/owendaigle/TRM-server-home-page/tree/jekyll-live](https://github.com/owendaigle/TRM-server-home-page/tree/jekyll-live) on my server (`jekyll-live` branch) every 15 minutes

Deploying includes pulling new code, deploying using jekyll, then serving using apache2.
